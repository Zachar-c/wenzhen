# 玄同纪八道 · 本地接入记录 v0.7

本次通过 Desktop Commander 更新本机仓库，保留旧档与旧传承（未提交 Git）。

## 已进入正式离线入口 lab.html
- 首页可选百兵、晦明、玄牝、执枢、阖辟、参同、乘物、观复八道；点选后新局按指定道途携带三只原创一转蛊、元石和专属蛊材。
- 新增原创Gu可玩32只：一转24只 + 二转8只。对应8张固定原创合炼方进入现有炼蛊台；保留月芒与白玉两张旧方。
- 创新内容明确标记 original_xuantong，不伪装成原著事实。侦察/攻击/防护/炼材蛊目前只接入可验证的既有动作语法；更高级的原设定能力尚未全部实现。
- 开局选择和资源保存于原有状态与存档，不另建平行游戏。未主动选八道时仍可按旧传承开局，以兼容已有测试/游戏流程。
- 所有256只原创蛊与192条候选配方以研究数据存在 data/xuantong_research.json。除8张已映射的首炼方外，其他研究方不能被游戏擅自执行。
- 八套二转首炼消耗原有投入蛊、实际蛊材与元石；结算不足不会半笔扣费。
- 可在普通商店购买原创一转蛊（不再把月光蛊作为必须核心）。

## 文件
- data/xuantong_live.json：正式接入的32只Gu + 八个开局 + 八首炼方
- data/xuantong_research.json：256只原创Gu + 192候选方研究库
- tools/build_data.mjs：数据投影整合，生成 js/data.js
- js/main.js、js/journey.js、js/gu_rules.js、js/alchemy.js：状态、首页选择、合炼、材料显示
- tests/xuantong_openings.test.mjs：新道途开局、存档和合炼原子性测试

## 界限
- 未实现完整256只Gu的战斗、1–5转所有候选方、重复获取高级蛊材、专属条件动作、相互克制和整体数值平衡。
- 二转首炼只在修为达到二转后可进行；不因选流派免费破境。
- 无蛊虫共鸣、阵位加成、通用任意合炼，也不增加独立喂食或杀招系统。
- 没有修改用户已有浏览器存档、没有提交/推送Git。
