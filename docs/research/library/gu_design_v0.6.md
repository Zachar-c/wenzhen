## 0. 本版最重要的纠正

- 八道皆从**原创一转蛊**开局：不再由月光蛊、白玉蛊、酒虫等经典原著蛊替代新道核心。
- 原著蛊只有少量经典支线和商店遗物，**不成为任何256只原创蛊的必需材料**。既有两条游戏配方保留在可选旧传承池，不删除旧世界。
- **去掉**蛊虫共鸣、杀招阵位、流派专属蓄能条、通用“任意两蛊相炼”。条件协作来自具体蛊的真实效果，炼方依赖指定活蛊、实物蛊材与转数。
- 游戏方式以已有《问真》商店、三战蛊槽、自动对战、炼蛊和阶段成长为底，不另造喂食和独立杀招系统。战蛊槽只限制数量，不产生摆放相邻收益。
- **八个名称只是本项目后世原创世界观**；承接47道的“知识转译”不等于全部旧道痕已被八道从物理层面统一。47条研究契约仅作选材证据源。

## 2. 玩家资源：只记录真的持有或正在发生的事

| 类别 | 玩家实际持有 / 操作 | 不得误造 |
|---|---|---|
| 货币 | 元石（买蛊、买材料、刷新、拓槽、炼方手续费） | 各派独立金钱/通用合流币 |
| 可交易实体 | 活蛊、已损兵胚、木胎、丹砂、界石、风羽、墨帛、契纹纸、活种等 | 没有来源就自动生成材料 |
| 知识资产 | 已知炼方、对敌调查结果、取得的旧传承 | 知道方就能零成本炼成 |
| 修行条件 | 修为转数、空窍可战蛊槽、资质及能力边界 | 把转数当成商店货币，越级无代价发动 |
| 交锋状态 | 气血、真元、真实目标/控制权、已投影、有效界标、存活根须、已验证攻击轨迹等 | “影点”“契能”“道韵”等全局可转换资源条 |
| 机会代价 | 触发次序、实际消耗的药料、失去的战蛊及交战时间 | 战斗结束取消未结成本、无限循环产物 |

**触发状态不是合成材料本身。** 例如“影”必须有光源、遮挡与承影面；“受控”必须有可辨识主人及具体授权或蛊术夺取手段；“看见征兆”不是全知或概率增益；“炉砂”与“玄铁屑”并非一个可以任意互换的通用元素代币。

## 3. 八道原创玩法机制、真实边界

### 百兵道
**核心**：百兵有形，持用有法：真实器胚与操持方式决定效果；失去兵材或握持便不能凭空御兵。  **玩法**：可见兵器形制：攻击、招架与破势依赖实在的兵胚。  **弱点**：敌人击碎器胚、夺去操持条件；换材需重新炼制。

- **1转（12只）**：引锋蛊——催动随身短刃胚刺击一名近敌，短刃损坏则不能用；守柄蛊——令持用兵柄卸去一次轻击，不反射伤害；试刃蛊——验出目标护具承受一式兵击的薄弱处；换锋蛊——收束兵锋以降低本次器胚损耗；悬扣蛊——固定一枚真正存在的短兵扣环；软柄蛊——令已备皮索兵柄暂时弯折避挡；骨钉蛊——射出消耗的一根骨钉伤敌；藏鞘蛊——将已握刀刃收回鞘内避开一次缴械；承骨蛊——支撑一段合格骨节兵器的关节；探锋蛊——用兵尖试探敌人一次格挡习惯；合柄蛊——扣合两段实际存在的短柄；听刃蛊——听取金刃碰撞的回声判断裂纹。
- **2转（6只）**：折锋蛊——令短兵一击后回收，下一次出手可再刺同一近敌；骨节兵蛊——操纵一柄由骨节与软柄构成的活动短兵；悬轮兵蛊——以悬扣驱使小轮刃绕持有者护身；藏锋匣蛊——收入真实短兵并在格挡成功后吐出反击；验兵蛊——确认敌方兵器破损部位，下一击专破其形；双柄蛊——操纵两段合柄兵具，但每次只能使一段攻击。
- **3转（4只）**：游节兵蛊——骨节兵能在击中阻挡后改变关节方向，绕开一次护具；回匣刀蛊——藏锋匣收回尚未碎裂的轮刃，再次击出；裂甲探兵蛊——验兵蛊发现护具裂纹后，以双柄兵具各击一次；牵机双刃蛊——两件实存短兵轮流牵制，敌人破坏其一则失去另一式。
- **4转（3只）**：百节承锋蛊——驱动多节兵器在一次攻势内改变三段方向，关节有碎裂上限；归鞘轮兵蛊——将轮兵和回匣兵法凝于一蛊，挡住攻击才可回返；断甲游兵蛊——依据已见裂甲位置改变双刃次序；盔甲完好则无追击。
- **5转（2只）**：万节藏锋蛊——操持一柄多材活动兵器，依损耗逐段折断而非无损换形；百兵归鞘蛊——收回尚存的受控兵刃组成短时防线；无兵器则无作用。

**合炼示例**：
- 引锋蛊＋守柄蛊＋玄铁屑×1＋18元石 → **折锋蛊**（2转）
- 折锋蛊＋骨节兵蛊＋藏锋砂×2＋46元石 → **游节兵蛊**（3转）
- 游节兵蛊＋回匣刀蛊＋击甲铁×2＋116元石 → **百节承锋蛊**（4转）
- 百节承锋蛊＋归鞘轮兵蛊＋合兵铆×3＋290元石 → **万节藏锋蛊**（5转）

### 晦明道
**核心**：晦明相待而生影：照明、遮挡、投影面缺一不可；影不直接等于黑暗与实体。  **玩法**：先有可见灯晖和遮蔽物，才有投影可追索；直接光术仍能作基础攻击。  **弱点**：黑暗无光、目标不投影、光源被移走；幻影不承受真实撞击。

- **1转（12只）**：藏晖蛊——储存一缕有来源的微光，释放时照亮并灼伤近敌；投影蛊——在已有光源下投出自身真实轮廓，干扰一次瞄准；遮灯蛊——以墨帛短暂遮住自家灯源，切断敌方识影；借光蛊——借已有火光使一次弱光刃可见；辨影蛊——辨别地面阴影归属何种实体；墨幕蛊——展开消耗的墨帛遮挡一条光路；折晖蛊——以折光晶将已有灯光转向侧面目标；照隅蛊——照亮遮挡物背后的一个狭窄角落；留影蛊——在受影面保留短暂轮廓，不复制主人身体；照尘蛊——照出扬尘使不可见物体留下遮光迹；映面蛊——以光滑器面映出对手一次动作；剪影蛊——截去已有投影的末端令其短时失去指向。
- **2转（6只）**：灯影蛊——固定微光与投影面，下一次受击时偏转敌人锁定；折影蛊——在折向的新光路上形成侧影，允许绕障侦测；识虚影蛊——对照照明与轮廓，识破一次伪影；隐晖幕蛊——用墨幕封住一束光并保留小孔供自身辨位；留影镜蛊——把一次已见动作投到映面供自己判断；断影蛊——切断一个已有的追踪影线，不影响实体。
- **3转（4只）**：光隙影蛊——沿真实光隙寻找被遮挡目标的影面弱点；明镜照蛊——用留影镜比对真身与伪影，抵消一次幻误；剪烛幽蛊——光源仍在时定点剪断敌方依赖光影的识别；藏照迷影蛊——先藏光再打开照孔形成一次短时佯影。
- **4转（3只）**：一灯万影蛊——由单一真实灯源投出多个可验证影位，灯灭全散；明灭照形蛊——明镜验身和剪影同时作用，真假辨认须耗真元；幽窗留影蛊——将已有光隙内投影短留用于二次侦察，失光即失效。
- **5转（2只）**：烛幽见真蛊——在明确光源、载体和受影面之间重建被遮形迹，非全知；晦明一息蛊——一次催动切换明路与暗幕，形成限时护与探；光尽则止。

**合炼示例**：
- 藏晖蛊＋投影蛊＋灯脂×1＋18元石 → **灯影蛊**（2转）
- 灯影蛊＋折影蛊＋照影银×2＋46元石 → **光隙影蛊**（3转）
- 光隙影蛊＋明镜照蛊＋藏晖砂×2＋116元石 → **一灯万影蛊**（4转）
- 一灯万影蛊＋明灭照形蛊＋映面晶×3＋290元石 → **烛幽见真蛊**（5转）

### 玄牝道
**核心**：生有根、养有料、蜕有余：蛊与木胎都是具体活物；不凭空创造生命。  **玩法**：活芽成长、根须阻挡、消耗春露治疗真实伤口；增长需要行动与时间。  **弱点**：活体遭毒害、断水，或对手一击烧毁根部；魂和肉不能随意互换。

- **1转（12只）**：含芽蛊——活芽刺出短须伤及近敌，须有存活木胎；守根蛊——根须缠成一层会被斩断的护面；引露蛊——牵引现有湿露滋润一道已受伤的根须；枯叶蛊——抛出一片真实枯叶扰乱敌方瞄准；食芽蛊——吞下少量春露使自身一条根须延长；剥壳蛊——剥落已有木胎外壳形成可丢弃的护片；扎须蛊——将活根须扎入近敌皮甲使其动作一滞；收种蛊——战后收集仍有活性的种粒，不复制蛊；辨枯蛊——辨别活木与腐木并对腐木施以断根术；护苞蛊——护住尚未绽开的芽苞免一次微损；萌刺蛊——用新生木刺击中近敌，伤害随存活芽数受限；续髓蛊——将消耗的露液导向确实断损的一截木髓。
- **2转（6只）**：养根蛊——生根在受击后固定损坏根须，减少下一次损失；护蜕蛊——以剥落的木壳换一次有限的护盾；棘缠蛊——木须扎住目标后萌刺追加一击；藏种蛊——保留一枚战斗后可用的活种，需要春露培育；枯荣辨蛊——辨别枯活结构并定向刈除一株寄生木蛊；髓露蛊——用露液修复自身木胎的一段已损结构。
- **3转（4只）**：回根护体蛊——伤害先由仍活着的根须承担，根断后防御降低；蜕刺丛蛊——弃木壳后由活芽长出一次棘丛，耗时且须有活芽；归种生枝蛊——用留存活种分化成一根可打击的枝，不再保留种粒；枯荣续髓蛊——区别活髓与腐髓修复一段木蛊组织，不能治好魂伤。
- **4转（3只）**：根脉千结蛊——多根互为支撑但每根有独立活性；斩根能破；春壳万棘蛊——舍弃有限木壳生成一阵刺枝并缓慢再生；归根木身蛊——从存活种粒构成木盾身，种粒耗尽即消散。
- **5转（2只）**：玄牝藏生蛊——将已活的根脉与种粒组织为持久木体，需稳定养分；万木归根蛊——在一定范围内接续已有活根进行守护，断根不可免。

**合炼示例**：
- 含芽蛊＋守根蛊＋春息露×1＋18元石 → **养根蛊**（2转）
- 养根蛊＋护蜕蛊＋护芽脂×2＋46元石 → **回根护体蛊**（3转）
- 回根护体蛊＋蜕刺丛蛊＋枯荣粉×2＋116元石 → **根脉千结蛊**（4转）
- 根脉千结蛊＋春壳万棘蛊＋根髓浆×3＋290元石 → **玄牝藏生蛊**（5转）

### 执枢道
**核心**：执枢非全能：必须有真实的主人、已授之令或可夺之权；命令不能取代蛊自身能力。  **玩法**：以已持有的蛊为对象进行临时调度、护持，攻击必须由真实蛊发出。  **弱点**：无权对象拒绝指令，断令遭反噬；不能未经许可改写誓约或盗取一切。

- **1转（12只）**：识主蛊——辨别一只己方已炼化蛊的主人识别印记；系令蛊——限定自己下一次拳脚或己方攻击蛊的合法目标，不产生额外攻击；解扣蛊——解除自己亲手附上的一条临时系令；令纸蛊——消耗一张实在的信纸记录命令内容；护主蛊——为自己所炼之蛊挡住一次轻度夺蛊尝试；断令蛊——切断已经失效的己方控制令；传令蛊——向己方已控制蛊传送一次合法目标选择；查印蛊——核验蛊上是否存在外来印记；副令蛊——记录一个后备目标，只有主令不成立才执行；封印蛊——以自身已知印纹暂锁一条己方令路；索引蛊——追踪自己留在物件上的一个可见控制印；归令蛊——召回一条自己尚未履行的临时指令。
- **2转（6只）**：验印蛊——识别自己与他人授权印纹的区别，无法凭此破解；传枢蛊——让两只己方已控蛊依次接受一次合法目标指令；护令蛊——在己方受夺时先解扣再封住原令；副命蛊——主令目标消失时改向预先登记的备选目标；索契蛊——确认原主人在场时查找临时控制链的来源；归信蛊——把尚未动用的己方令纸收回一张。
- **3转（4只）**：同主连令蛊——两只同主蛊按明确先后发动，第二只仍另付真元；封枢换令蛊——封闭己方被窃令路后在下一次行动换令；双令巡察蛊——先检验两段命令是否来自同主，再发出不冲突的一条；还契明印蛊——收回自己尚未兑现的临时命令；已生效不可逆。
- **4转（3只）**：九令归枢蛊——在自己掌控的多蛊间合法安排一次指令队列，每只照付代价；明印护主蛊——主动识破并拒绝一条不符合主权印记的夺令；知令反系蛊——发现敌方留下的真实控制印后切断其一处传递。
- **5转（2只）**：万令有主蛊——管理自身已控蛊的一次多层合法命令，不能控制陌生蛊；大道归印蛊——校验并重封数条既存控制权链，缺原印便失败。

**合炼示例**：
- 识主蛊＋系令蛊＋契纹纸×1＋18元石 → **验印蛊**（2转）
- 验印蛊＋传枢蛊＋副命简×2＋46元石 → **同主连令蛊**（3转）
- 同主连令蛊＋封枢换令蛊＋索契墨×2＋116元石 → **九令归枢蛊**（4转）
- 九令归枢蛊＋明印护主蛊＋归信印×3＋290元石 → **万令有主蛊**（5转）

### 阖辟道
**核心**：阖则有界、辟则有门：具名位置与有限时间窗共同约束开闭，不任意瞬移。  **玩法**：在实测坐标内设置短时界口，防守或截击的窗口可被敌人等到关闭。  **弱点**：标记被拆、距离过远、计时终了；并不倒流时间。

- **1转（12只）**：认隙蛊——识别眼前两处障碍之间实际存在的窄隙；定标蛊——投出一枚随身界石击中近敌并在实物落点留下界标；掩扉蛊——在已固定界石旁合拢一道短时护障；听刻蛊——记录自身上一道界口持续了几息；引门蛊——以真元使已定界石开一道仅容小物的口；折门蛊——使一处自家小界口向原坐标闭合；窥隙蛊——从确已打开的小孔观察遮挡后方；守时蛊——在标定时间内延续一道护障一息，额外付元；投砾蛊——把随身一枚小石穿过已开的短距界口；闭罅蛊——封闭一道自己已打开的界缝；双标蛊——预先确立两个可见近距标记但不穿行；数漏蛊——用实物刻沙计算一次界口关闭时刻。
- **2转（6只）**：隙门蛊——连认隙与引门开一处近距小门射出随身石粒；时扉蛊——护障有确定关闭时刻，临末时可反弹一次冲击；双门标蛊——两个已勘坐标间仅转运小物，不能移人；窥门镜蛊——已开孔后可以探测另一侧一次真实物体；封隙蛊——将自己的开孔短时封成挡截面；回标蛊——将耗掉的一枚自家界石从旧位置召回。
- **3转（4只）**：移砾界门蛊——两标都在近距时转移已持石弹，跨越正面挡护；须臾护扉蛊——已知关闭时刻的界障在终止前增加一次挡击；藏门照隅蛊——从特定界孔窥见遮障物，不暴露全地图；封界回标蛊——收回自家旧界标并封闭它开启的口。
- **4转（3只）**：一线天门蛊——延长两枚实存界石间的小物通路，但不放大无限距离；合辟守界蛊——在一处自家界口持续挡击或传递，二者择一；归标折界蛊——断开跨区界口时收回一个保全的旧界石。
- **5转（2只）**：阖辟双门蛊——已知两处界标间建立限时可撤销通路，封门后无效果；须臾乾坤蛊——极短时关闭一处已开界路以挡一次攻势，不能回溯战果。

**合炼示例**：
- 认隙蛊＋定标蛊＋界石×1＋18元石 → **隙门蛊**（2转）
- 隙门蛊＋时扉蛊＋窥孔晶×2＋46元石 → **移砾界门蛊**（3转）
- 移砾界门蛊＋须臾护扉蛊＋封界灰×2＋116元石 → **一线天门蛊**（4转）
- 一线天门蛊＋合辟守界蛊＋回标钉×3＋290元石 → **阖辟双门蛊**（5转）

### 参同道
**核心**：参异求同、坎离守位：只改变已知配方中确有条件的反应，不是万物任意合炼。  **玩法**：炉火与砂粒也可成为弱攻和护体手段，但真正长处是按配方节省特定损耗。  **弱点**：材料比例失衡、反应时窗错过、炉体破裂；不得使用万能减费。

- **1转（12只）**：试砂蛊——辨明手上两种已知砂材的粗细，不推衍未知方；护炉蛊——撑起一面会损坏的炉泥薄障；火筹蛊——放出一撮限量炉火灼伤近敌；寒签蛊——察觉炼液表面冷热异常；分液蛊——把已知反应液分出一小份并损耗少量；封炉蛊——以炉泥封住裂开的一个炉口；砺砂蛊——以粗砂磨破单一软甲外皮；看胎蛊——观察半成蛊胎是否仍有完整外壳；还液蛊——收集可用未变质的余液一小份；伏火蛊——压住指定炉火避免一息过热；定壳蛊——给已成形蛊胎短时护上一层炉泥；引温蛊——将现有火筹分向另一处炉膛，火总量不增。
- **2转（6只）**：定炉蛊——以试砂和护炉限定某一已知炼方的炉泥损耗；坎离蛊——已知冷热条件下调节一次炉液状态；砂火蛊——将砺砂与炉火连用，砂耗后才可灼入外皮；分胎蛊——按有据配方把半成蛊胎分成两份有损副胎；伏火壳蛊——暂压一炉火护成形的蛊胎防过热；回液签蛊——确认余液合格才收回，若变质则弃掉。
- **3转（4只）**：同炉定相蛊——对一种已验证材料配比锁定稳定反应窗，其他方无效；焰砂破胎蛊——用砂火切开敌方松散护甲并留下炉砂损耗；双胎验炉蛊——分胎两份中仅保留通过看胎检验的那一份；回液伏火蛊——用余液代替本来要消耗的一份同种炼材，严格限一次。
- **4转（3只）**：两仪同炉蛊——同一炉内分隔两种已证相容工序，仍分别消耗原料；金砂回胎蛊——用破胎余砂再炼一个次级壳片，成功依配方；明炉复验蛊——连续检验同一蛊胎两次，第二次消耗材料确认。
- **5转（2只）**：参同化育蛊——依据完整既定蛊方把两段工序固化为一只专蛊，方外无效；坎离归炉蛊——让已验证的两路冷热工序共用一套炉体，工序不互换。

**合炼示例**：
- 试砂蛊＋护炉蛊＋丹砂×1＋18元石 → **定炉蛊**（2转）
- 定炉蛊＋坎离蛊＋看胎晶×2＋46元石 → **同炉定相蛊**（3转）
- 同炉定相蛊＋焰砂破胎蛊＋伏火砂×2＋116元石 → **两仪同炉蛊**（4转）
- 两仪同炉蛊＋金砂回胎蛊＋余液瓶×3＋290元石 → **参同化育蛊**（5转）

### 乘物道
**核心**：乘物而不役物：必须先有流、风、地势等实际介质，才能借其路而行。  **玩法**：根据确有的风流和地纹改变实物射击路径，环境无媒介时保留近距基础攻守。  **弱点**：绝缘介质、静风、泥地阻断；不能“所有伤害统一转导”。

- **1转（12只）**：试流蛊——投出微量导砂探一条实际可通的气流路径；听风蛊——识别近身风向并放出一枚小风羽划击；踏脉蛊——循坚实地面纹路避开一次近地冲击；借坡蛊——借实际斜坡让石弹滚向近敌；逐波蛊——在水面存在时沿水纹送出一枚小石；束风蛊——把存在的侧风限制在短时窄路内；探砂蛊——撒砂看障碍物后有无穿堂风；听石蛊——从石地传回震音分辨一次落点；回羽蛊——收回尚未损毁的风羽，需同向气流；压浪蛊——压平近身真实水波降低一次溅击；走罅蛊——从已知细缝射出一枚小实物；回坡蛊——若坡道尚存，将滚石引回一次，石损即止。
- **2转（6只）**：借风蛊——沿已辨风向引导实物羽刃一击，风息则停；石脉蛊——沿坚实石纹把一步足力传给近敌脚下；流砂蛊——沿真实水流或坡势运砂，阻碍一次追击；归羽蛊——顺相同方向风流收回一枚完好羽刃；穿罅蛊——将小石穿越已探明的细缝击中遮挡近敌；抚浪蛊——压制一片局部水波，减少一击水溅损伤。
- **3转（4只）**：逐风折羽蛊——在真实风向转弯处折转羽刃，逆风时无法返；地脉传震蛊——借连续石地传播一次冲击，松软土会消散；砂石入隙蛊——把流砂经已知细隙送至敌人脚边令其减速；回潮护体蛊——借局部潮流卸去一次水击，离水环境不成立。
- **4转（3只）**：乘风千里蛊——在连续可追踪风道中远送羽刃，并非穿越封闭界域；因地成势蛊——将足力沿硬地纹连续折向，地断则止；流砂罅阵蛊——不用摆放共鸣，凭物理裂隙形成有限砂阻路。
- **5转（2只）**：乘物无滞蛊——择一已验证介质传递一式攻击；换介质需重验；风石同途蛊——以风携石经同一实存通路攻击，遇实墙即止。

**合炼示例**：
- 试流蛊＋听风蛊＋风羽×1＋18元石 → **借风蛊**（2转）
- 借风蛊＋石脉蛊＋归羽丝×2＋46元石 → **逐风折羽蛊**（3转）
- 逐风折羽蛊＋地脉传震蛊＋细罅铁×2＋116元石 → **乘风千里蛊**（4转）
- 乘风千里蛊＋因地成势蛊＋镇浪珠×3＋290元石 → **乘物无滞蛊**（5转）

### 观复道
**核心**：观其往复，察其已见之兆：预测必须有可观测周期，绝不直接支配天意与概率。  **玩法**：通过上一回合敌人的真实动作，选择下一次保护或克制，第一轮信息不足。  **弱点**：敌人变招、节律被隐藏、事件不可重复；不保底改概率。

- **1转（12只）**：辨兆蛊——辨别敌人刚露出的一个真实起手征兆；听息蛊——听敌气息间隙以护住下一次轻击；记痕蛊——记下一道实见攻击轨迹，使下一记拳脚试探原落点；数息蛊——数已发生两次攻击的间隔，不知未知未来；观刃蛊——观察敌方出刃前真实的手部变化；记漏蛊——记录一个已经结束的技能冷却长度；候雨蛊——凭可见雨云判定是否将有一次近距湿风；听步蛊——记下近敌已出现的步伐次序；验兆蛊——在下一次敌人出手后检验旧兆是否仍真；回简蛊——把已记的一条事实换成可读纸简，消耗旧简；断妄蛊——发现一项预兆已失效后放弃错误追击；知几蛊——敌人连续两次按同一节奏出手后择机刺击。
- **2转（6只）**：重息蛊——记录两次相同起手后提高下次防备的准度；循痕蛊——沿一条已经发生的攻击轨迹设下一次格挡；验机蛊——对已观察的节奏进行一次真假复核；察步蛊——敌人旧步法再次出现时才能进行一次截击；回兆简蛊——将已验证情报制作一次性可售纸简；止妄蛊——预测一旦失败就停止追加真元，减少本次浪费。
- **3转（4只）**：三息观机蛊——三次相合的起手后才能提前护住同式攻击；回痕截式蛊——按已见轨迹发起一次反制；新式攻击不可预判；真假循环蛊——记录敌方节奏突然变化并放弃错误的追击；候兆知几蛊——把同一先兆核验两次才可触发弱点刺击。
- **4转（3只）**：观微见著蛊——多次实际交锋后识别一名敌人的固定习惯，不适用于陌生人；周而复始蛊——在同一战内识别重复动作，周期断则无法提前防；返观止妄蛊——先校验旧情报有效性，再对相同招式选防或攻。
- **5转（2只）**：万象观复蛊——推定已观察敌人的一项循环招式下一次窗口，不能预知全局；知几守一蛊——对确证重复的一个招式做一次精准反制，其余照常受击。

**合炼示例**：
- 辨兆蛊＋听息蛊＋旧年轮×1＋18元石 → **重息蛊**（2转）
- 重息蛊＋循痕蛊＋察步纸×2＋46元石 → **三息观机蛊**（3转）
- 三息观机蛊＋回痕截式蛊＋回兆简×2＋116元石 → **观微见著蛊**（4转）
- 观微见著蛊＋周而复始蛊＋止妄砂×3＋290元石 → **万象观复蛊**（5转）

- **誓炉验印蛊**（执枢道 × 参同道）：炼炉开锁前核验自家印记，不能强制改变他人权属。媒材：丹印纸。
- **听隙渡蛊**（阖辟道 × 乘物道）：沿真实风路经过小界口传送一粒砂，开口关闭即止。媒材：风界砂。
- **旧方验兆蛊**（参同道 × 观复道）：只针对历史已试炼方的可见炉征判断失效风险。媒材：旧炉简。
- **借风引锋蛊**（乘物道 × 百兵道）：让确有的风推动一片实存金属薄刃，不得逆风无耗。媒材：风钢。
- **烛影知几蛊**（观复道 × 晦明道）：比较曾见敌影步态与当下光线，影形变则撤回判断。媒材：照兆纸。

## 5. 关系网不是美术图，合炼边的含义要严格

每一个 `recipe` 都有 `id / inputs[{id,qty}] / materials[{name,qty}] / stone_fee / output / rank_required / principle / restriction / status`；`inputs` 中的蛊虫被**消耗**，不同于战斗中协作、交易中借用或来自旧道的**知识启发**。

- **32条同转一阶改炼**：源头是1转旧蛊，材料明确，获得新的1转实用蛊。
- **48条本门一→二转合炼**：每次用2只指定1转蛊与媒材，六条分支/道。
- **32条本门二→三转合炼、24条三→四转合炼、16条四→五转合炼**：无一以“已有同道标签”代替确定的输入。
- **40条跨道炼方**：8对相邻关系每对4条，加8条远端交叉边；其中四转及五转包含先前炼得的跨道核心，不是把两只最高转随手相加。

### 真正的投入竞争：两个详细例子

- **折锋蛊**：可用于炼游节兵蛊、炼剪锋影蛊。同一份母蛊被消耗后不能同时走两条路线；需要从交易/敌方掉落/原配方再获得第二份。
- **灯影蛊**：可用于炼光隙影蛊、炼荫芽蛊。同一份母蛊被消耗后不能同时走两条路线；需要从交易/敌方掉落/原配方再获得第二份。

**防自动推导错误**：v0.2旧库中没有经过可执行验证的各种“迹道、契道、衡道”占位节点不迁入。更新库是**替换主库**而不是与旧292个节点累加；旧库可作为历史备份。

## 6. 经典蛊虫保留：但永远不是八套开局的门票
