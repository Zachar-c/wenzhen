# 《问真》：后世开道假说与一至五转蛊虫炼制网络 v0.2

**定位**：可审查的原创游戏世界研究资产，不是原著设定集，也不是可直接安装的平衡版蛊虫数据库。2026-10-12。已核对 Library 《蛊界生成原理》V4-R18 终审、第三论、第二论及《问真》当前 GitHub README、产品需求与现版炼方。

## 最重要的纠错

上一版“共鸣/杀招阵位/每派独立资源条”一律撤回；空窍战蛊槽是游戏库存/驾驭限制，不赋予相邻蛊虫额外作用。**原著没有证明蛊虫同列、同色、相邻能够增伤**。本设计不写任何这类效果。

同样，原文没有所谓一套允许所有旧道蛊虫互炼的“万道兼容万能律”。本文件的连线分三种：F 原著证实的具体配方；C 原创可辨对象/材料角色的候选；H 核心操作桥仍未知的想法（不得直接进入可炼游戏）。未给出配方的知识借鉴以 `relations` 存储，绝不冒充炼方。

## 一、以原著兵道和影道作为吸收式流派的硬标准

| 案例 | 已有的严格依据 | 不能虚增的结论 |
|---|---|---|
| 车尾兵道 | 金道知识转译为铁棒蛊方；变化道成果结合兵道产生皮鞭蛊方 | 不能说“所有金道、变化道蛊都能无损变为兵道蛊” |
| 顾影仙君影道判断 | 影不仅关联暗，还依赖光；人物提出未来可能反过来统合光、暗二道 | 小说中的可能性**不是已成历史事实** |
| 月光蛊旧炼方 | 月芒偏威力；月痕偏射程；月旋偏曲线；月霓裳偏防御，后者路线能指向宝月光王蛊 | 不据此推导“任意四只蛊能互换配方” |
| 阵灵救急案例 | 一座特定阵在主核抽离后，阵灵临时调大量自爱凡蛊保结构 | 不允许低转蛊在全场任意无损替核 |
| 星念仙蛊炼液 | 指定炎、水材料的道痕比例影响炼液合格与否 | 没有“一切水火属性自动抵消”的定律 |

**开道判据**（研究口径）：新流派必须有新的稳定作用对象与独有 K；能够吸收至少3类旧道技术并在新语法中表达，并在成本、适用条件、材料与效果上产生非同构多种新蛊；可对比原旧道更廉价的直接方法；至少通过局部技术可实施性审查。若无独立新型道痕证据，最多称**后世新技法学派**，不能伪称已开辟全新“道”。

## 二、四个功能组织型的后世开道候选

### 迹道｜限定残留的生成→识别→指定后继消耗
**吸纳研究**：研究可归属的「作用残留」：是谁留下、留在何处、尚存多久，后续怎样读取这一特定残留。 **来源领域**：月道、炎道、水道、毒道、兵道、血道、音道、光道、暗道。
**原著支点**：炎道愤怒小鸟留下短时道痕、火囚后续利用；月痕是不同射程蛊，不能把名称当作同种接口。
**关键桥**：K-JI：特定残留与后续消费者的实体传递桥，不得假设可读取全世界全部道痕。
**淘汰线**：没有原蛊留下的真实残留，或残留不可识别时，迹道不应凭空追踪、锁定或复制原威能。
**与原旧道的真正区别**：如果每条支线都只是月道追月、炎道循火，那么它仍是八个旧道杀招。只有找到可被多个来源携带、但具有同一“残迹读写”结构的客观新型蛊/道痕，才可能反过来把旧道“追索类”技术转译到迹道。此跨源物理接口目前**未证**。

### 契道｜可确认的主体→合法约定→单次履行或解除
**吸纳研究**：研究已有权限下，自愿缔约、确认履行者与到期条件的蛊术。 **来源领域**：信道、律道、气道、阵道、奴道、血道。
**原著支点**：毒誓等誓约术能拘束当事人；信道传讯不等于同步或许可。
**关键桥**：K-QI：具体约束的授权主体与一次性履约条件；没有授权接口不得跨人改写结果。
**淘汰线**：不能擅自支配不愿签约的敌人、复制誓约处罚给第三方，不能直接把消息蛊当成自动行动执行器。
**与原旧道的真正区别**：若只是信道毒誓、律道限制拼盘，就不能叫新道。必须在当事者明确授权的边界内，建立独立的“约定条件与履约状态”作用体系，且绝不能把对方的惩罚嫁接到无同意第三人。

### 续道｜存续结构的局部识别→合法备用→有时限的降级维持
**吸纳研究**：研究特定系统主蛊撤离或损坏时，如何有界维持剩余的结构或低阶功能。 **来源领域**：阵道、土道、气道、木道、奴道、兵道、炼道。
**原著支点**：阵灵调度大量自爱凡蛊，暂时代偿自爱仙蛊的阵位，但不是全阵通用替核律。
**关键桥**：K-XU：每种结构自有的备用接口与断供时限；跨系统扩张需个别验算。
**淘汰线**：不允许低转辅蛊凭空替代全部高转威能，不允许对已坍塌系统无代价修复。
**与原旧道的真正区别**：不是被动回血或护甲，更不是阵道万能替核。核心是**保住哪些连接/通路但明确牺牲哪些功能**，广泛跨阵/载具/资源生态的普适性必须逐案成立。

### 衡道｜指定材料→测量可比条件→控制某一工序的反应窗口
**吸纳研究**：研究特定炼制步骤的异道材料比例、互扰、相消与阶段稳定。 **来源领域**：炼道、水道、炎道、光道、暗道、金道、木道、土道、血道、毒道、音道。
**原著支点**：星念仙蛊炼制的一项原液工序，炎、水材料道痕比例有约束，材料环境和损耗影响结果。
**关键桥**：K-HENG：只限被实测配方确认的互作窗口，不把一处水火原液推成万能炼道定律。
**淘汰线**：不是任意属性两两抵消，更不是拿两种蛊放相邻格子获得加成。
**与原旧道的真正区别**：目前很可能只是炼道某些工序的高级分支。除非原著后世发现确实独立的“互作窗口型”道痕/野生蛊与资源点，否则应留作**炼道工艺组织体系**，而不是强行第五十个大道。

## 四、真正有效的合成网络，不能仅以“线很多”为标准

### A. 原著确定的分叉：月光蛊与玉皮蛊

```text
月光蛊 + 小光蛊×2 → 二转·月芒蛊（攻击增幅）
月光蛊 + 痕石蛊 → 二转·月痕蛊（射程增长）
月光蛊 + 旋风蛊 → 二转·月旋蛊（曲线月刃）
月光蛊 + 玉皮蛊 → 二转·月霓裳（护身；后续有五转宝月光王路线，但缺中间炼方）
玉皮蛊 + 白豕蛊 → 二转·白玉蛊（护身强化）
```

这一小网已经有四个真实策略：投资月刃威力、射程、弯曲轨道或护甲。同一只玉皮蛊又在月霓裳与白玉之间构成真实竞争。这里不需要共鸣槽/阵位。

### B. 新道吸收式的竞争：同一旧蛊可能成为数条候选道路的来源

**本稿精确示例**：`支纹蛊`（原创旧道源蛊）既被设想用于续道的阵骨支线，也可作契道联守体系的材料启发，还能在旧阵道内部升炼。它的三条路线必须比较：是否真能维持阵骨？是否只是用信道发出守阵约定？旧阵道补纹是否更便宜？如果后两者已经足够，前者不能借“新流派”身份获得额外功能。

`调液蛊`同样可以被原炼道内强化、续道炉液保护路线、衡道材料比例路线竞争使用，但它只负责**实际调液**，不能因为合成说明里带“衡”字就无条件中和其他道痕。

**16条跨流派研究路线**列为 H 而非可炼 F。每条给出独立的边界说明；若关键 K 为 UNKNOWN，不应该放在商店“点击必合成”。

### C. 一个完整的原创研究递进样例

以迹道火烬支线作示例——原初“炎道打击留下可被火囚利用的短时道痕”是原著局部事实，但下面不是原著炼方：

1. **一转烬点蛊**：必须有真实火烬或由蛊本身留下短时烬点；尚不能观察无形的所有炎道道痕。
2. **二转辨烬蛊**：区分自身留下的烬点与普通烧灼痕迹；若不能区分，应退回炎道侦察术。
3. **三转逐烬蛊**：要有一个明确接受该烬点的后续炎道攻击；没有该接口只能看到烬点，不能凭空追击。
4. **四转连灼印蛊**：尝试让多个独立烬点分别被后续蛊读取；必须有个别限定和供能，不能自动引燃全场。
5. **五转长焰留迹蛊**：仅当较长时间内烬点可稳定存在且保留原来源判据，才考虑凝为高阶蛊。否则五转形态判为失败候选。

它与单纯“火蛊升到五转”不同之处在于，研究对象始终是**可保留、读取、消费的作用残迹**。但其二至五转的独立技术 K 没有被证成，严禁写作已经完成的游戏蛊方。

## 五、玩家真正拥有并能操作的东西

| 资产或状态 | 来自蛊界的正当语义 | 谁改变它 |
|---|---|---|
| 蛊虫与蛊材 | 拥有可丢失、可炼制、可卖的具体蛊虫/材料 | 交易、炼蛊、掉落、争夺 |
| 元石 | 市场交易、修行与炼蛊的通用经济约束 | 所有流派 |
| 真元与修为 | 一至五转催用资格、真元品质与容量 | 所有流派；特殊蛊可合法减少某次消耗，但不能虚空产元 |
| 气血与伤势 | 肉身受伤、治疗与不同防护效果 | 兵、月、血、木、药等具体蛊术 |
| 蛊方、传承和情报 | 知道如何炼制、材料在哪里、目标可否作用 | 炼道/信道/相关侦查蛊 |
| 已有的实际效果状态 | 真实的炎道残留、阵纹损伤、已立毒誓等 | 迹/契/续各研究一个具体作用对象；**不是新资源条** |
| 炼制材料的实物品质 | 年份、道痕属性、比例、完整程度等 | 衡道目前只能在具体工序中提出精修工艺 |
| 时间与寿元 | 催动时间窗、移动或等待机会；寿元不可任意凭修炼恢复 | 宙道/寿蛊等具体已存在手段 |

**取消**：共鸣值、阵位加成、流派特有无来历代币“迹点/契能/续力/衡势”、任意两蛊相邻得增幅。**保留**：原书的实际效应、投入消耗、养用炼以及真实存在的机会成本。

## 六、四级验收：是否配得上被称为《蛊真人》游戏

**门1 原著事实**：每只F蛊至少具有引用位置、转数证据、效果边界；不从别人的游戏攻略回填原著绝对公式。

**门2 新蛊可理解**：每只C蛊要清楚“来源载体、供能、具体改变、谁负责控制、失效条件、炼方材料角色”。缺任一关键项就不是可炼版本。

**门3 新派不可还原**：必须通过“同样元石/真元/蛊材投入下，比旧道方案产生**不同而非仅更强**的效果”比较。若旧炎道追火痕已经做到同样事情，迹道同型招式淘汰；若旧阵道补纹更廉价，续道不自动胜出。

**门4 1—5转构筑连贯**：一转多样获取；二转分叉；三转形成专门化；四转引入昂贵工艺和目标限制；五转获得新战术上限，但不能把旧低转辅助蛊全部淘汰。至少应出现真正的投入争夺、重复使用的旧蛊素材以及在转数许可/资金/成蛊风险下不可逆选择。

## 七、目前对这套大网最严格的结论

这不是292只已设计完成的蛊虫，其中相当多还只是**有归属、有名称、有作用边界的候选记录**；不是181条已验证的合炼配方。尤其四转、五转，很多核心K仍然未知。

下一轮若要形成**能真正交付游戏的蛊虫体系**，优先选每流派最具辨识度的一条路线，逐只验证其外部供能、效果承接与低成本替代。任何验证不成立的候选应删除或退回旧道，不能因为已经有五转名字就硬上。
