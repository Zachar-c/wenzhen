# 《问真》研究资料使用与实现约束

> 目的：让 Codex/其他执行代理利用 Library 研究资产，而非不经审核地把候选文本直接装入游戏。
> 来源：ChatGPT Library `/问真/体系设计/`；归档日期 2026-10-13。此目录是**选定的只读快照**，后续重新同步要记录来源和版本。

## 优先级（按适用领域，而不是盲目互相覆盖）

1. **正在运行的游戏**：对应入口的当前可执行代码、测试、版本化合同（M1 的 `docs/M1_IMPLEMENTATION_SPEC.md` 和 `data/m1_contract.json`）。已有运行规则、存档、数值不能被研究文档静默改写。
2. **产品裁决**：以《团团勇者大乱斗》的**实际产品完成度和游玩吸引力**为目标，第一版可以不做喂养、突破、材料成本等。产品体验优先于尽可能多地复刻理论系统。
3. **新内容设计参考**：`gu_design_v0.6.md` + `gu_catalog_v0.6.json` 为**八道原创蛊及合炼候选的首选检索来源**，目前是 `DESIGN_ONLY__NOT_IMPORT_TO_GAME_AUTOMATICALLY`。
4. **名称/美学**：`school_naming_v0.5.md` 约束名词、八道定位与视觉一致性。
5. **探索性资料**：`gu_network_exploratory_v0.2.md` 包含更广泛未证候选，不是当前游戏内容真源。历史研究结果中被否决或缺证的机理不得借“设计稿”升级为已证事实。

## 每新增一只蛊、一个敌人或系统之前（最低内部审计）

- **先检索**主设计文件的名称、ID、转数、作用对象、成立条件、失败情景和来源；已有相近能力优先复用，不无故造重复蛊。
- 提交一张**实现映射**：`source_file / source_id / origin_class / intended_mechanic / kept_conditions / simplified_conditions / known_risk / tests`。
- 区分 `CANON`（小说有可追溯原文）、`GAME_ORIGINAL`（本游戏原创）、`HYPOTHESIS`（需证伪的推断）、`IMPLEMENTED`（实际代码已运行）、`REJECTED`（被否决）；这些是不同维度，不能混同。特别是 **GAME_ORIGINAL ≠ CANON**、设计实体 ≠ 可直接运行的技能。
- 新功能必须形成新的**玩家选择和可观察的战斗/经济反馈**。没有必要的趣味增量就否决，不为凑数量、MCP/skill复杂性或通用 Roguelike 模板而加。
- 优先在现有战斗核内映射关键因果条件；可以去掉首版不需要的材料喂养成本，但**不能悄悄把需要媒介/观察/真实损伤的技能变为无条件高伤或万能效果**。
- 新蛊/配方必须有真实可达的来源、合法触发条件、失败测试与至少一个能和其他构筑明显区分的场景。绝不能只给卡面写新名字却复用所有机制。
- 先写审计结论，再实施、浏览器与数据测试，最后在 PR 留出处和改动理由。**不得修改 M1 冻结快照使错误测试变绿**。

## 导入的资料到底是什么

| 文件 | 性质 | 导入范围 | 是否可直接编码 |
|---|---|---|---|
| `gu_catalog_v0.6.json` | 256 蛊、192 合炼记录、八道及联系的设计实体库 | 完整 Library 快照 | **否，须按入口合同转译** |
| `gu_design_v0.6.md` | 八道起始、1–5转演化、媒介/约束、合炼示例 | 完整 Library 快照 | 否，材料与高转机制未获首版许可 |
| `school_naming_v0.5.md` | 八道定位、术语与美学规范 | 完整 Library 快照 | 作为风格校验 |
| `gu_network_exploratory_v0.2.md` | 跨流派探索性蛊网（文中称292实体/181炼方） | 完整 Library 快照 | **否，候选更早更宽** |

`gu_catalog_v0.6.json` 中的 `provenance:C_ORIGINAL` 是**《问真》原创候选**，不是原著事实；该 JSON 的 `meta.execution_status` 标记明确禁止自动导入。不要仅因“有配方”就开放实际炼制；当前 M2 没有实现对应材料、转数与炼制系统。

## 当前 M2 的已知设计差额

- M2 原有 24 只初始蛊、近期另有 2 只 **N201 裂势 / N202 饮锋**，这两只**不在 v0.6 目录**，属于暂存的已实现原创试验，不应反向擅自改写 Library v0.6。
- 已有 M2 是六战原型，仍不是 15 战成品，CI 通过不代表达到参考产品的完成度。
- 现有 GitHub `AGENTS.md` 指向正式 `lab.html`，M1/M2 目前是**隔离实验分支入口**；本目录只提供研究引用，不授权把 M2 自动替换正式入口或合并 `master`。
- 《蛊界本源论》的大量研究总控和状态文件很大、包含历史版本及否决假说；**本次没有把它们当已证实规则整体复制进仓库**。未来需要某项机制时，应标明具体研究段落、证据等级、反例后摘录，而不是把长文当代码约束。
