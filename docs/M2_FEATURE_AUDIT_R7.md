# M2 R7 功能审计：商人定向寻蛊（2026-10-13）

**判定：通过最小切片，不新增额外货币/材料，也不采用战后三选一。**

## 问题
M2 有27只实装蛊与明确职业差异，但非初始蛊只能盲抽货架或定向追猎少数敌人。G112 知几蛊即使玩家计划针对固定招式构筑，也缺少可支付代价的主动获取路径。

## 候选反证
- 任意免费指定：破坏商店随机供应和价格取舍，否决。
- 寻蛊后自动入仓：省掉购蛊选择，并与既有货架经济重叠，否决。
- **一轮一次，付2金币委托商人寻到指定的一转蛊，替换一个未锁且未被委托占用的货架格；仍要付4金币买蛊**：通过。
- 新增线索货币、合炼材料、传承任务地图：首版成本大、无需引入，否决。

## 约束
1. 目标必须是当前27只已经运行的 `GU`，而非 Library 256候选的自动解锁；合法 `GM` ID。
2. 每轮仅一次委托；现金至少6（2委托费+4购买费），库存低于12且至少1个可覆盖货架槽；扣2后仍需付4，玩家可以放弃购买。
3. 锁定货品不能被顶替；新寻得的商品本轮刷新仍保留，下一轮不自动强制保留，除非玩家自行锁定。
4. 重新加载保留寻蛊目标及一次性使用标记；非法ID/不够钱/满仓/无空闲货格不修改任何状态。
5. 价格不随道途改变；有来源的商人寻货行为是本项目原创机制假设，并非小说原著记载的普遍商店能力。
6. 新增 UI 仅使用现有商店区的原生 select 和按钮，不修改视觉专属 CSS/HTML；视觉专项仍在独立 PR。

## 退出与验证
Node tests 验证金额、购蛊、刷新保留、存档和无效请求；Chromium 应完成八道六战回归。若“所有蛊均可2金币随时寻到”使原货架/敌源失去意义，再降低为按幕开放或有限来源约束，而非盲目增加经济系统。**本轮只验证经济合法和操作可行，不能自称玩法平衡已通过。**
