# 《问真》五转蛊虫先行：以果推因设计裁决 v0.1
2026-10-13 · M3 玩法主线 · **仅设计约束，不是五转功能已实装**

## 先纠正研发顺序

过去 M3 主要以“做出一只二转→打六敌→再找下一只二转”方式推进。这样虽能测试小取舍，但无法解释为什么玩家要长期追求某条合炼链。**自此改为五转终局能力优先，再倒推每级构筑积木、敌人反制和经济供给。**

Library v0.6 已经有八道×每道两只五转候选（共16只）、及其部分固定配方。不是重新发明世界观或命名。本轮先选每道**一个主目标（共8只）**；其余8只是未来可替代目标，不代表无效。严格来源：`docs/research/library/gu_design_v0.6.md`、`docs/research/library/gu_catalog_v0.6.json`。可机器核验的反推蓝图：`docs/design/m3_rank5_reverse_blueprints_v0.1.json`。

## 五转“终局玩法”先定义结果，而非伤害数值

| 道途 / 终点 ID | 五转目标 | 玩家真正得到的不同能力 | 成立前提 | 会被什么打败 |
|---|---|---|---|---|
| 百兵 B501 | 万节藏锋蛊 | 实体兵器命中后按完好关节连续变节，最多三段压迫 | 兵胚存在、上一段真实命中、关节完好 | 缴械或关节毁坏 |
| 晦明 Y501 | 烛幽见真蛊 | 沿光源、遮挡、受影面确认伪影，揭伪创造进攻窗口 | 光、载体、受影面、观察记录 | 熄灯、没有真实影面 |
| 玄牝 S501 | 玄牝藏生蛊 | 持久战存活活根可在防护与根刺间再分配 | 活根与养分，不凭空再生 | 断根、灼烧、断粮 |
| 执枢 Z501 | 万令有主蛊 | 对已拥有已验印蛊发起至多三层合法连令 | 真正控制权与各蛊准备条件 | 原印失效、命令冲突 |
| 阖辟 H501 | 阖辟双门蛊 | 两处已标定地点间开限时攻防通路，封门断路 | 两个可验证的界标 | 界标毁坏、路径被截 |
| 参同 T501 | 参同化育蛊 | 已验证固定配方的两步工序固化为单槽专蛊 | 有真实方谱及工序媒介 | 破炉、步骤倒置、方外失效 |
| 乘物 M501 | 乘物无滞蛊 | 对风/石中已验证的单一介质建立传击通路 | 介质和可达路径 | 断风、实墙阻隔 |
| 观复 G501 | 万象观复蛊 | 用确实观察到的循环招式推定下一次窗口，精准化解一次 | 同一敌人重复招式有足够证据 | 变招、隐匿节律、新对手 |

**禁止把五转统一实现为“伤害+50%”“冷却减半”。** 五转改变的是可采取的战术，而不是只有数字。每种必须有发动证据、显式反馈、硬反制、获取代价。

## 从结果倒推能力链（先因果，后材料）

下表按每道一条主脊梁写出 1→5 转，实际每一级还有一个同转材料蛊；完整双输入及 v0.6 参考材料列于 JSON，不能把“只有主蛊”误认为可无损单链升级。

| 道途 | 1→2→3→4→5 主脊梁 | 逐级必须继承的能力 |
|---|---|---|
| 百兵 | 引锋→折锋→游节兵→百节承锋→万节藏锋 | 实际刺击→回收→关节改变方向→多节可承伤→多节连击 |
| 晦明 | 藏晖→灯影→光隙影→一灯万影→烛幽见真 | 光源→受影→折光路径→多影核对→揭伪 |
| 玄牝 | 含芽→养根→回根护体→根脉千结→玄牝藏生 | 活芽→根须成长→损根续接→多根编织→活根守攻选择 |
| 执枢 | 识主→验印→同主连令→九令归枢→万令有主 | 归属→验印→短连令→多指令顺序→多层合法调度 |
| 阖辟 | 认隙→隙门→移砾界门→一线天门→阖辟双门 | 识别位置→建立一点门→移走可达砾→限时通路→两标往返 |
| 参同 | 试砂→定炉→同炉定相→两仪同炉→参同化育 | 验媒→单炉锁态→两工序定相→工序衔接→方谱固化 |
| 乘物 | 试流→借风→逐风折羽→乘风千里→乘物无滞 | 判断真实风→借风→延长传导→跨位但不穿墙→择一媒介 |
| 观复 | 辨兆→重息→三息观机→观微见著→万象观复 | 真实观察→已重复招式格挡→验证循环→预测单一窗口→反制循环 |

设计注意：**晦明 Y201 的现有游戏化“盾变强”版本已在 M3 实战验收失败并撤回。** Library 的 Y201 节点仍作为更远终点的一环，但必须重设计为“有光路条件的影面证据”，不能直接复活失败版。B201 与 G201 在当前 M3 只是局部原型，不等于整个五转路线已有数值平衡。

## 原始固定方与发行经济必须分开

v0.6 四个跨转配方含物资与元石：
- 1→2：两只一转蛊 + 一个指定材料×1 + 18元石。
- 2→3：主蛊 + 同转辅蛊 + 指定材料×2 + 46元石。
- 3→4：主蛊 + 同转辅蛊 + 指定材料×2 + 116元石。
- 4→5：主蛊 + 同转辅蛊 + 指定材料×3 + 290元石。

**这些仅是 Library 的设计档案原价，绝不能直接移植到《问真》当前金币经济。** M3 一局只有六战、每轮+5金币、商店单蛊4金币，照搬该成本根本不可达。发行版必须先从“目标五转在一局哪一阶段可达”反推原料供给、2/3/4转附蛊到货节点、获得速率、可见进度与舍弃旧蛊的机会成本。

## 反推的验证与开发顺序

**阶段 0（本轮）**：先确立八个五转的终局效果与硬失败条件；从 v0.6 现有192条配方里核对所需的32条跨转主方。所有节点目前都标记 `DESIGN_ONLY_NOT_IN_RUNTIME`。在未有长局经济前不允许将其导入商店和战斗核。

**阶段 1（M3-A）**：选择百兵与观复各一条完整线路作为两种异质样本。逐级实现“保留原蛊/付代价合炼”的对照，必须每级有变化的动作因果、非数值性新能力、清晰反制及获得渠道。晦明的链首先修正失败的Y201，不同时铺开八道。

**阶段 2（M3-B）**：先定一局实际能逐级拿到2、3、4、5转的目标节奏。随着敌人公开克制机制，让玩家有理由提早储备同转辅蛊、选择追猎或定向商人，防止终局蛊永远不可得；本阶段**不得把重复敌人算作有效节点**。

**阶段 3（M3-C）**：8道目标需求覆盖、商店经济配对试验、真实固定画幅交互、多种子长局（能赢、能失败、能偏航）、每个终点至少一个强势场景和硬反例。视觉专项负责五转“成型感”的资产和演出，但不能决定玩法和材料逻辑。

## 开发硬门槛

- **先设计五转再设计前置条件，不意味着先把五转扔进六战原型。** 当前真实运行态仍只有已批准的一、二转样例。设计数据必须显式标记不可自动导入。
- 一条链只保留能解释最终效果的关键节点；中转若只是升级伤害，合并、重写或删掉，不机械保留祖传配方。
- 如八条终局路线在六战经济内根本不可达，应**重做局长与供应结构**，而不是塞金币或把五转强行作为初始蛊。
- 最终目标由玩家“提前看见但暂时够不到”，每一步可选择投入或转向；不是强制完成线性科技树。
