# M2 R5 — 新蛊能力内部审计与裁决（2026-10-13）

## 审计的问题

R4 的“夺蛊即换装”缩短了操作，但如果所有可夺的都是既有蛊，收集动机和战斗方式变化仍不充分。本轮不是为达成数字而新增16蛊，而是验证两种**可见因果**的新能力能否构成真正不同的构筑方向。

## 候选与反例

- **无条件高伤攻击蛊**：只提高数字，会推动无脑换高 DPS；**否决**。
- **新养成等级、突破、材料**：不能解决短局选择无趣，开发成本极高；**否决**。
- **裂势蛊 N201（攻击窗口型）**：敌人已经宣告并处于蓄势窗口时才能造成5点伤害，冷却10 tick；敌人招式更频繁时机会更多，但单靠它不构成稳定输出。**通过**。
- **饮锋蛊 N202（承伤反击型）**：确实损失气血时才蓄血势，下一 tick 反击，伤害上限6，冷却10 tick。护盾完全吸收伤害时不触发，因此与纯防御流存在真实取舍。**通过**。

## 玩法目的和蛊界推导边界

裂势鼓励针对敌人攻击节奏；饮锋鼓励衡量生命代价与反击收益。两蛊属于 M2 **原创战斗机制假设**，不是《蛊真人》原著既有蛊虫事实。二者可由玩家观察战前敌人攻击特征后追猎，分别配置在逐影刺客（N201）和镇关铁卫（N202）身上，胜利才可获得。商店随机池也开放，但不会伪装成无来源的战后三选一。

## 必须验证的行为

1. 八道起始三蛊不能悄悄变成新蛊；M2 蛊池由24增至26，M1仍是24。
2. 裂势不在敌人未宣告时释放；只在明确攻击窗口生效。
3. 饮锋不因单纯盾吸收或规避而生效；只在真实气血损失后于下个 tick 反击。
4. 六战完整路径、敌源战利品、M1黄金快照、Chromium 真浏览器均不回归。
5. 若仅能证明日志里触发，不等于证明玩家体感有趣；保留后续实际游玩验收项。

本轮不额外引入养成资源、全新战斗 UI 页面、敌人数量或固定三选一。参考标准仍然是《团团勇者大乱斗》的实际产品完成度。
