## 已交付

- 整备页重排为参考图的左侧紫色出战板、右侧米白四件商店、底部六列两行蛊仓、左下角色资源牌和右下迎战徽章。商店、蛊仓和五个出战位同时可见。
- 增加关卡详情、蛊录/合炼和规则抽屉。商店保留购买、双件锁定上限、付费刷新、定向寻蛊；蛊仓保留出售、上阵与下阵。
- 悬停卡自动避让目标；右键物品打开插画、蛊性、tick 属性和配方组成的三栏卡。右键敌人使用同一查询框，仅显示公开招式。查询不暂停战斗，敌人信息按 tick 更新，未公开变招不泄露。
- 战斗页采用全屏场景、敌我状态条、中央 tick、分列蛊阵与敌方意图、角色立绘、事件焦点、暂停/继续、立即结算和战报抽屉。原有战斗结算规则保留。
- 图片使用仓库已有的蛊虫图、角色/敌人图及场景图；面板材质、徽章、地板和色彩由 CSS 绘制。没有新增或伪造游戏规则数据。

## 验收结果

- 浏览器视口保持 1920×1080；整备页无横向或纵向溢出，所有主操作在首屏。主要区域坐标与计划表一致。
- 实际浏览器交互通过：锁定、免费刷新后保留锁定、购买扣费和库存增加、上阵/下阵、切换追猎、打开抽屉、鼠标悬停、右键查蛊、Esc 关闭、右键查敌、查询中战斗继续推进且敌情更新、战报抽屉跨 tick 保持打开、暂停冻结 tick、继续推进、立即结算只生成一次结果。
- 控制台无运行时异常。`node --check` 检查三个 M2 脚本通过；`git diff --check` 通过。

素材仍沿用项目现有的水墨蛊图、角色图和写实环境图，因此整体 HUD 布局与参考图一致，人物与场景画风仍受现有素材限制。此限制已在本次实现中保留为素材来源事实，没有用截图裁片或占位插画冒充新成品美术。
