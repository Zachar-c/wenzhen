# M2 R3 功能内部审计：选择追猎目标

结论：**有条件通过**，实施最小的可见敌情分支，拒绝无意义的随机选关。

- **动机与趣味**：玩家为特定蛊虫选择敌人，同时承担不同 HP、护甲和招式压力；选择影响实际战斗与战利品，不只是切换卡片。
- **世界逻辑**：敌方携蛊线索来自 M2 原创敌人资产设定，属于玩法假设，不宣称原著事实。夺蛊不是凭空领取。
- **方案对比**：比战后无来源三选一更主动；比新增复杂地图、侦查消耗、传承链更低成本。当前六轮每轮两条明确的追猎线索，默认目标保持旧流程，旧 M2 存档未新增字段时仍可按原线路。
- **代价**：重复追猎同一敌人仍可能发生；目前每轮路线只在同一幕敌人池内二选一，尚未建立独立战场生态；并没有实现 15 场完整游戏。
- **失败退出指标**：若不同目标选择不会影响战斗或奖品、可在战斗中改目标、刷新获得多次奖励，则立即修复或撤回。Node/Chromium 要覆盖切换、重载、非法目标和结算。
- **具体设计**：第1–3轮可选 [散修/野猪]、[野猪/刀客]、[刀客/野猪]；第4–6轮 [悍匪/刺客]、[刺客/铁卫]、[铁卫/刺客]。目标名称、生命、护甲、首次宣告时间及携蛊线索在进入战斗前明确展示。不会新增货币/喂养/炼蛊/固定三选一。

后续仍以《团团勇者大乱斗》的产品完成度为参照：此实现只补了一个主动追求目标的原型，不等于达到成品质量。
