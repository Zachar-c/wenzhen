# 《问真》三项核心规则里程碑 / 研究总控
版本：Rules Gate R0.1 | 日期：2026-10-12 | 性质：设计裁决，不是游戏已实施

## 总目标
在派出 v0.8 正式编码任务前，固定可以追溯原著或有明确游戏化解释的经济、真元战斗、修行时间三组规则。任何 R0.1 原创候选都不得自动升级为原著事实。八道原创蛊可用，但其效用必须与真元、媒介及炼方条件一致。

## 不可混淆的四级标签
- F-N（小说事实）：有卷、节、情境、原文证据；必须保留适用地点与时间。
- F-S（设定整理）：由维基或二手研究归纳，待小说原文复核，不称 F-N。
- D（由事实作出的推导）：说明前提及反例，不能伪装成原著定价或蛊方。
- G（游戏投影/原创设计）：为了可操作、可视化或可重玩而新设，必须声明如何避免矛盾。

## 先冻结的三个裁决
1. **货币是真实元石**；不得把一转普通蛊定价成 6–14 元石，也不能以“玄同纪货币改革”任意除以20。
2. **世界层真元不是 6/8/10/12/14 MP**；游戏内部压缩必须仅是注明意义的显示或战斗投影，不可与元海容量/品质混用。
3. **一局跨越数个修为大境界，不等于一天之内修成五转**；跳过日常时间不等于时间和喂食不发生。

## 真实工程现状（需要修正，但现在不擅自修改）
- data/xuantong_live.json：八个开局现金 85–105，全部一转起始蛊的市价及库存出入理由未建立；二转炼费统一18。
- data/balance.json：大境界升级现有数值 5/12/20/30 元石；这是游戏早期投影，不得作为修为的唯一解释。
- js/data.js 由 tools/build_data.mjs 生成；不能编辑生成物作为经济真源。
- 原 Web 胜利现金为普通/精英/层主 base 3/8/15。可作为特定小规模随身元石的 *G* 值，但绝非原著蛊虫市场价格缩小的证明。
- v0.7 已把 32只原创蛊映成通用 strike/shield/inspect/component，不能宣称完整继承其各自特殊能力。

## 当前决策待核
- 普通蛊师的现金与蛊虫市值不对等，开局三蛊的取得方式暂按“旧传承已获物”作为 G 提案，不假装普通散修免费拥有三蛊。
- 原著三至五转蛊虫稀缺不等于八道路线不能到五转；但其来源必须经传承、机缘、炼蛊、交换解释。
- 高品质真元的“十倍”首先是催动能力/能量质量参照，不能直接转写成伤害十倍。
- 一局每次行动代表多少时间、如何计食料及连续战斗，需要 T1/T2 审定后才定。

## 验收纪律
每项规则提供：事实锚点 -> 适用前提 -> 运行时字段 -> 反例 -> 走盘种子/测试。找不到证据就改为 D/G；没有结算就标未实现。正式 Agent 不得自行补造原著事实。
