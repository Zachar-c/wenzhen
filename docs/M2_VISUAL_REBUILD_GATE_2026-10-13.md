# 《问真》M2 视觉重建｜第八轮执行与验收契约
日期：2026-10-13
工作分支：feat/m2-visual-pass；目标：feat/m2-extended-run；PR #3 Draft。

## 结论
在不改玩法的约束下，当前「程序 SVG 蛊纹 + 剪影人物 + CSS 闪光」只能作为原型占位。不能被宣称为商业级美术。视觉改造必须将资产制作、运行时接入、截图审查作为一个闭环。

## 美术基线
- 电影感国风奇幻：冷青夜景、点状暖金光、清晰主体、稳定背景层次；低噪点，不堆叠装饰花纹。
- 角色：主角与六敌统一身体比例、轮廓和打光，禁用文字占位或未经检验的剪影当终稿。
- 卡面：已有全部实装蛊保留原数据；卡面必须有不同的主体形态，视觉上可以区别攻/防/反/辅/标/疗/察，不改变战斗含义。
- 动效：起势→出招→命中/吸收/反击→余韵；信息反馈优先于光效，低动效模式须正常可读。
- 授权：每张新素材登记作者/生成手段、生成日期、用途、许可/来源及替换状态。概念拼图不是独立资产，禁止直接裁作正式卡面而不验收。

## 可操作的交付关卡
G1：制作至少 1 个完整关卡纵切片（主角、一个敌人、4 张已实装蛊、普通攻击/盾/反击）；资产要分别可引用，不靠 CSS 形状冒充。
G2：资源接入后截 1280×720 / 1366×768 / 1920×1080 / 390×844 实际 Chromium 游玩状态，不把概念图记为游戏截图。
G3：测试道途、商店、12 只满蛊仓、战斗、夺蛊、结算；视觉审图逐张标记裁切、错位、对比度、插画质量。
G4：经人工审图通过，再统一扩展到全部 26+ 只已实装蛊和六名敌人。
G5：仅由玩法 Owner 在最新 M2 HEAD 下择机整合；视觉 PR 不自行合并。
