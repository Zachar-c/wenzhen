# M2 玩法主线 R6 · 知几蛊能力转译审计（2026-10-13）

## 背景与边界
视觉专项已移交独立对话及未来分支 `feat/m2-visual-pass`，本轮只修改 `js/m2_game.js` 战斗能力和 `tests/m2_progression.test.mjs`，不修改 `m2.html`、CSS 或美术资源。M2 PR #2 继续 Draft，M1 与 master 不变。

## 内部功能审计结论：有条件通过

来源：Library `/问真/体系设计/问真_八道原创资源与合炼体系_v0.6.md`；GitHub 快照 `docs/research/library/gu_design_v0.6.md`，观复道一转 **知几蛊**。原设计：“敌人连续两次按同一节奏出手后择机刺击”；核心限制“预判必须有可观测周期，敌人变招、节律隐藏则不保底”。

| 核查点 | 裁决 |
|---|---|
| 玩家决策 | 选择面对节律稳定的敌人以换得特定输出；或在变招多的敌人前换下该蛊 |
| 来源与正当性 | 来自既有 Library v0.6 的 **G112**、一转原创候选，不是原著已证蛊 |
| 简化原因 | M2 现有战斗核已有敌人每次真实宣告 `move.name` 和 `feint.revealed`，无需新增独立预知/概率或资源系统 |
| 实装规则 | 相邻两次敌人真实宣告 **同一招式名** 才形成可检验证据；已公开起手且仍在蓄势时，冷却12 tick，攻击3 |
| 失败条件 | 第一式、交替招式、尚未揭示变招、已经命中的当前招式不能触发 |
| 收集渠道 | 保留现有商店候选池的 `market_or_event` 来源；非开局三蛊；未硬塞战后三选一 |
| 退出条件 | 与普通攻击结果无异或不需重复证据便触发，则撤回/修正，不增加无条件数值 |

## 真实工程改动
- `js/m2_game.js` 中增加 G112；把当前战斗的 `lastDeclaredMove` / `repeatMoveCount` 放在当前战斗瞬态而非跨战不合理继承；敌方宣告后再检查有据可依的攻击。
- 同一招连续第二次才可出手；混合变招的敌人不成立。没有让攻击透过黑箱知道下一次招式。
- 新测试检查首招不触发、重复确实触发、交替变招持续不触发，以及 G112 非初始蛊。保留 8 道途六战 Chromium 流程。

## 不夸大结果
这是一个已设计技能向战斗核的**有损但有因果的转译**：同招不等于对全部节奏的复杂推断，未知的未来也不会自动推演。商店随机性仍影响能否购入该蛊；当前只完成一只非初始一转蛊的竖切样例，不代表 Library 256 蛊实装，不代表达到《团团勇者大乱斗》的产品完成度。

## 下一期设计方向
验证玩家是否能因敌情主动搜集/换装不同能力；若获取渠道完全不可控，优先审计有来源的商贩专售/追猎收益，而不是继续无差别扩大商店池。视觉专项的 CSS/HTML/美术交由独立 PR。
