# 问真 UI 复刻计划：1920×1080 / 16:9

状态：已按计划完成 1920×1080 / 16:9 实现，并完成实际 Chromium 浏览器验收。验收记录与四张当前页面截图见 [实现与验收](UI_REPLICA_1080P_REVIEW.md)。

实现采用 CSS 构筑/纸色面板、现有问真场景与角色素材，并复用原有 M2/M3 规则。人物和环境仍受仓库现有素材风格限制；没有将参考截图裁成运行背景，也没有把临时占位图宣称为新美术成品。

## 1. 交付目标

入口 m2.html，基线为 b5f2a0d 加当前未提交的查询、下阵、暂停/继续改动。主文件 m2.html、js/m2_game.js、js/m2_visual_pass.js、js/m2_inspect.js、css/m2_ink.css。

交付四张1920×1080真实页面：整备工作台、物品悬停、右键物品/配方查询、战斗场景。参考用户五张1280×720截图，按1.5倍换算主要轮廓、占比、层级与位置。目标包括页面构图、面板材质、装饰框线、图标大小与交互，不再以原网页卡片布局作为视觉基础。

用户已确认「复刻参考图布局与色彩」：采用紫色构筑区、米白纸色商店、彩色物品信息头、半透明遮罩与大场景；蛊虫、角色、环境换成问真内容。此决定替代上一轮保留暗色标本色系的默认方向。

## 2. 画布合同

- 设计画布固定1920×1080 CSS像素；验收截图固定1920×1080，浏览器缩放100%，deviceScaleFactor=1。
- 根画布铺满视口，页面无纵向/横向滚动。库存、货架、出战阵、迎战操作在一屏内完成。
- 当前只实施此尺寸；不设计手机、竖屏、窄桌面或可伸缩断点。坐标、字体与命中区域使用同一套画布单位。
- 允许滚动的区域只有配方列表、长说明、追猎详情与完整战报的局部容器。
- 背景与装饰不截获鼠标，浮层在画布坐标系内定位；本体与查询层共享坐标，避免缩放后指针错位。

商品与库存避免变成四张长说明卡。物品图、选择状态、数量/槽位、价格留在场上；名称与核心字段进入速览。出战位可以使用统一五块带色底的物品牌，不能引入背包形状、旋转、拼格或不同占格规则。

商品保持四件，刷新占独立操作位；锁定最多2件，购买、刷新和出售费用采用现有规则。下阵只移出出战，不销毁物品。库存12实例始终可见；重复蛊按实例显示，查询与操作不得合并成一种蛊的总数。

追猎选择位于顶部遭遇详情弹层：当前敌人、可得蛊与公开线索可查询/切换；主画面在迎战附近显示当前目标。切换目标后马上更新迎战文字和摘要，关闭弹层即可继续构筑。

## 4. 悬停速览复刻

- 参考图中的彩色标题/类型标签、浅纸正文、属性横条与操作提示。初始尺寸约462px宽，纯效果卡约315px高，含属性卡约480px高；内容允许合理增高，但不越界。
- 字体：名称30–34px、标签20px、正文22px、字段22px；价格与关键数字26–30px。主画面常用文字20–24px，辅助说明不小于18px。
- 悬停180–200ms打开，离开关闭；同一物品的图、价格牌和锁定图标共用同一查询对象。
- 卡片优先放在对象左上或左侧，按实际卡片尺寸检测四边并翻转定位。不得压住被查看物品、刷新按钮或迎战主操作；长文不能靠固定120px高度估算边界。
- 底部显示明确鼠标提示：左键执行当前合法操作、右键查询；商品锁定位置单独提示锁定/解锁。
- 展示道途、类型、完整效果、冷却tick、首次触发tick、当前持有/出战与禁用原因。没有伤害/COST字段的蛊不伪造数字；tick不改写成秒级攻速。
- 删除重复原生title与卡片内重复长说明；页面切换、迎战和结算时清除旧速览，修复前次预览中旧提示挡住战斗顶部的问题。

需要的成套资产：1920×1080整备背景1张、1920×1080战斗背景1张、出战板/纸色商店的边框与材质、三类信息头、迎战徽章与刷新/锁定/金币/状态图标、相向的我方与代表敌人透明立绘。蛊物图复用现有资源，缺失映射列出并补齐。原始参考截图仅用于构图核对，不裁成运行时场景底图；问真内容采用现有合法素材或新制作素材。

实现阶段如需生成原创场景/角色图，先按目标槽位尺寸与参考视觉制作统一资产；本计划阶段不调用图像生成、不宣称美术已交付。

## 9. 验收与交付

视觉：参考图先等比放大到1920×1080，再与实际截图对齐叠图。比较主要面板边界、留白、角色尺寸、按钮位置、物品牌密度和信息卡层级。主区域轮廓/锚点偏差目标≤16px，装饰和文字按内容适配；原参考的物品数不对应当前规则时以本计划的映射为准。无全页滚动、裁切、文字重叠或悬停遮住关键操作。

功能：真实鼠标购买/锁定/刷新、满仓/缺钱原因、装备/下阵/出售、同名实例、合炼缺件/耗材/结果、追猎切换、迎战、悬停/右键/关闭、暂停/继续/快结算、奖励/下一轮、整备重载。查询中重绘和结算不留下失效浮层；隐蔽信息保持隐蔽；新增调度不重复timer或结算。检查M3同入口下关键字段与长配方。

浏览器证据来自固定1920×1080当前版本；托管Chromium用本地HTTP验证交互，离线file://验证若受策略阻断单独记录。不能以过去的1366/390截图或零测试运行证明本次1080p复刻。

交付四张主要画面截图、实际代码、素材清单/来源、简短验收记录。本轮仅完成计划文档；当前运行界面仍为上轮暗色标本样式。实现与发布是后续工作，提交/推送/发布按用户指示。
