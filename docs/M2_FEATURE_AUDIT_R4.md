# M2 R4 功能内部审计 — 战利品即时换装

**问题**：前一轮可选择目标并夺蛊，但缴获后只收入蛊仓，必须再寻找装备槽并手动卸旧、装新。获取的蛊不保证参与下一战，获得能力的反馈闭环割裂。

候选：A 自动替换（快但破坏自主权）；B 新增独立强化/强化槽（复杂且与既有五槽系统重复）；C **在战利品结算直接选择替换现有出战蛊，原蛊仍留仓，或选择仅入仓、变卖**。裁决：C，通过。

**理由**：把“夺蛊—舍弃旧上阵能力—验证变化”压缩成一次有意识操作；不需要新货币或来源不明的三选一；沿用蛊虫实例/上阵装备规则。

**安全边界**：替换选择必须指向本轮已装备的合法实例；满仓必须先明确舍弃仓库中的一个实例，且不得同时要求替换刚舍弃的实例；不合法选择不消耗奖励、不修改金币/蛊仓/轮次。收入未选择替换时不自动装备。原出战蛊换下后仍保留仓内，可后续改装。

**验收**：成功夺蛊替换：装备数不变，新蛊实例进入原槽，旧蛊仍在仓；非法替换原子失败；默认只收入和变卖行为不回归；M1 冻结快照照常验证。后续需要通过真实浏览器操作验证。

**欠缺**：该设计只改善构筑操作闭环，并未新增蛊虫能力本身，也不代表达到《团团勇者大乱斗》的美术、反馈和长局内容完成度。
