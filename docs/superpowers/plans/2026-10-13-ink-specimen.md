# 墨蛊标本视觉重构 Implementation Plan

**Goal:** 将用户提供的墨蛊标本规范落实到现有 M2/M3 页面，保护玩法和存档。

**Architecture:** 主代理只调整 m2.html 和 js/m2_game.js 的展示模板。独立 CSS 文件替代旧 M2 样式链；视觉脚本统一标本与人物剪影回退。浏览器验收覆盖可见操作、手机首屏、缺图、键盘与减少动态。

**Tech Stack:** 原生 HTML/CSS/JavaScript、离线 SVG、Playwright。

## Global Constraints

- lab.html/M1 与所有经济、战斗、库存、合炼、存档函数保持原逻辑。
- 使用用户色板、字体层级、间距尺度。金色主按钮只给迎战；生命与护盾分开表达。
- 附图为构图参考；缺资产用统一、可识别的标本/墨色剪影，不能宣称完成正式绘画资产。
- M2 六战与 M3 十六轮标签按模式显示。减少动态兼容系统设置和页面开关。
